# clanker-experiments

This repository holds pull requests for various AI projects and experiments.
Each project lives in its own pull request, where its implementation, results,
and progress can be reviewed and discussed.

Browse the [pull requests](https://github.com/reaperhulk/clanker-experiments/pulls)
to see the experiments.

Inspired by [alex/claude-experiments](https://github.com/alex/claude-experiments).

Current experiment: [libheifer](libheifer/), a pure Rust libheif implementation in progress.
